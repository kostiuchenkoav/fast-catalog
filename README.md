# Каталог товаров

Каталог на 5000 товаров, который остаётся быстрым при большом объёме данных. Поиск, фильтр по категории и сортировка сохраняются в адресе страницы, поэтому ссылку можно отправить с уже настроенным видом.

> **Демо:** _добавьте ссылку на развёрнутое приложение после деплоя_

## Почему это быстро

- **Виртуализация списка.** В DOM попадают только карточки, видимые в окне, плюс небольшой запас. Из 5000 товаров обычно рендерится 15–30 элементов.
- **Ленивые изображения.** `loading="lazy"` и заданные `width`/`height` дают загрузку по мере прокрутки и отсутствие сдвигов макета.
- **Отложенный поиск.** Фильтрация запускается через 250 мс после последнего символа, а не на каждое нажатие клавиши.
- **Разделение кода.** Страница товара загружается отдельным чанком через `React.lazy`. Главный бандл не содержит её код.
- **Мемоизация.** Список товаров и категории вычисляются один раз и кэшируются в модуле данных.
- **Один кадр на скролл.** Обновления позиции прокрутки сворачиваются через `requestAnimationFrame`.

## Стек

- React 18, TypeScript в строгом режиме
- React Router 6 с параметрами в адресной строке
- Vite
- Vitest и Testing Library

## Быстрый старт

Требования: Node.js 20 или новее.

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # тесты
npm run build    # проверка типов и production-сборка
```

## Структура проекта

```
src/
  components/
    Controls.tsx        Поиск, категория и сортировка
    ProductCard.tsx     Карточка товара с ленивым изображением
    VirtualGrid.tsx     Виртуализированная сетка
  data/
    generate.ts         Детерминированный генератор тестового каталога
    store.ts            Кэш каталога и поиск товара по id
  hooks/
    useWindowScroll.ts  Отслеживание прокрутки, ширины и отложенное значение
  lib/
    catalog.ts          Фильтрация, сортировка, форматирование цен, query string
    virtualize.ts       Расчёт видимого диапазона строк
  pages/
    CatalogPage.tsx     Главная страница каталога
    ProductPage.tsx     Страница товара (ленивая загрузка)
```

## Данные

Каталог генерируется в браузере из seed-значения, поэтому проект работает без бэкенда, а тесты всегда видят одни и те же данные. Чтобы подключить реальный API, замените `getProducts()` в `src/data/store.ts` на запрос и добавьте загрузку с состояниями ожидания и ошибки.

## Адресная строка

| Параметр | Значения | По умолчанию |
|---|---|---|
| `q` | любой текст | пусто |
| `category` | название категории | `all` |
| `sort` | `relevance`, `price-asc`, `price-desc`, `rating-desc` | `relevance` |

Неизвестные значения `sort` заменяются на значение по умолчанию.

## Тестирование

```bash
npm test
```

Тесты покрывают фильтрацию и сортировку, разбор адресной строки, расчёт видимых строк, число колонок, маршрутизацию и поведение каталога (результаты, фильтры, страница товара и ошибка «не найдено»).

## Производительность

Проверяйте в Chrome DevTools или Lighthouse в режиме production:

```bash
npm run build && npm run preview
```

При первом открытии в DOM должно быть не больше нескольких десятков карточек, а полоса прокрутки должна соответствовать полному списку.
